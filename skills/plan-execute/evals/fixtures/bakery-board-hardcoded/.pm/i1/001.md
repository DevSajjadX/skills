# Customers can book a pickup slot that is already full

## Problem

Customers can book a pickup slot that is already full, so the bakery cannot fill every order on time.

## Done when

- A customer who picks a full slot sees "That slot is full, pick another" and no order is created.
- The booking check and the slot list read the same capacity number.

## Rules

- Capacity is per 30 minute slot.

## Not in this item

- Cancelling an order and freeing its slot.
