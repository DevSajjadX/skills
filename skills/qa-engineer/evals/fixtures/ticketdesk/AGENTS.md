# Ticketdesk

A small support-ticket app for two fake teams. Web app on a random port printed by `make dev` (line "web ready at ..."), API behind the web origin's `/api/*` proxy. The API's own port is internal.

## Rules a compiler will not catch

- Sign-in answers the same for a known and an unknown email on purpose (anti-enumeration).
- The shared "Public status" board lists tickets from every team on purpose (ADR-0004).
- Unauthenticated requests for a page redirect to `/signin?next=...` with a 302.
- Every non-GET request needs `X-Requested-With: ticketdesk-web`.
- `openapi.json` is generated by `make gen`; CI fails when it is stale.
- Anti-goals: no email notifications, no billing. The `NOTIFY_EMAIL` flag is off on purpose.
